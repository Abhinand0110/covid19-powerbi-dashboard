COVID-19 Power BI Dashboard

An interactive analytics project visualizing the global spread and impact of COVID-19 using Power BI.
This dashboard provides insights into confirmed cases, deaths, recoveries, and country-level trends to better understand the pandemic.

📊 Features

Global Overview: Total cases, deaths, recoveries, and active cases

Country Analysis: Compare cases, deaths, and recoveries across countries

Trends Over Time: Line chart with dynamic filters (cases, deaths, recoveries)

Insights Page: Key takeaways and observations in simple text format

Interactive Filters: Slice and analyze data by country and metric

🛠️ Tools & Technologies

Power BI Desktop – Dashboard creation and data visualization

Excel / CSV – Data preprocessing

GitHub – Version control and sharing

📌 Insights (Highlights)

Global cases crossed 19M, with over 12M recoveries and 713K deaths by July 2020.

Recovery rate (46.8%) is much higher than mortality rate (5.2%), showing positive progress.

US, Brazil, and India together account for more than 60% of total global cases.

The steepest growth in cases was observed between May and July 2020.

Countries like Australia show a higher recovery-to-death ratio → effective containment.

Despite recovery, active cases remain nearly 48%, posing continued risks.

🚀 How to Use

Download this repository (click the green Code button → Download ZIP).

Extract the ZIP file on your computer.

Make sure you have Power BI Desktop installed. (You can download it free from Microsoft Store).

Open the .pbix file inside the extracted folder.

Explore the dashboard interactively 🎉
